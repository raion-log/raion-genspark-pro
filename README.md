## 주요 기능

- 텍스트 프롬프트 기반 이미지 생성 자동화
- 배치 처리 (1-6개 프롬프트씩 처리)
- 13개 이미지 생성 모델 지원
- 다운로드 방식 선택: PC에 바로 저장 (기본) / AI 드라이브 저장
- NSFW 감지 시 자동 중단
- 탭 닫힘 감지 + 다른 탭 이동 시 백그라운드 동작 유지
- 실패 배치부터 재시도
